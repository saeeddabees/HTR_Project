# Contribution logs and peer evaluation

Deliverable 12 - **one contribution log and one peer evaluation per student.**

| File | Who fills it | How |
|---|---|---|
| `contributions.md` | Team (together) | Who owned which part of the project - one table for the whole team |
| `log_<name>.md` | Each student | Copy `CONTRIBUTION_LOG_TEMPLATE.md`, rename it to `log_<your-name>.md`, fill it in |
| `peer_<name>.md` | Each student | Copy `PEER_EVALUATION_TEMPLATE.md`, rename it to `peer_<your-name>.md`, rate every teammate |

Tips

- Link evidence: commit hashes, file names, experiment run names (e.g. `attention_aug_seed1`), report sections, slides.
- Peer evaluations are usually submitted privately to the instructor - check whether yours should be committed or emailed.
