Mahmoud Mohamed · Training protocol

Three seeds per model, chosen on validation CER

  • CTC loss, Adam, lr 1e-3, gradient clip 5
  • GRU / BiLSTM: 20 epochs, batch 8
  • Attention runs: 10 epochs, batch 4
  • Seeds 0, 1, 2 → report mean ± SD
  • Best-validation checkpoint → one test pass

Every run is logged to experiments/*.json - 23 runs in total.
